# Starship Survivors

Starship Survivors is a small top-down survivor game built in Godot 4.5. The core loop is simple: pilot a ship, survive waves of enemies, collect experience, and unlock weapons and upgrades.

This project started as a way to learn game development, systems design, and the Godot engine. I’ve been using it to practice things like scene structure, gameplay systems, enemy spawning, progression, and UI flow.

## What’s included

- A playable survival loop with enemies, upgrades, and basic progression
- A few menus and screens for profile, skins, and challenges
- Systems for weapons, pickups, difficulty scaling, and score tracking

## Running the project

Open the project folder in Godot 4.5 and run it from [project.godot](project.godot) or play the web build at https://funkywhale.github.io/Starship-Survivors/.

This is a personal project and still very much a work in progress, which is part of the point.
